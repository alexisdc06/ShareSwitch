One window. Any content.

ShareSwitch opens a window that mirrors any other window, live. You share that one window once, and every switch after that happens inside it.

  1. 1

    Share the ShareSwitch window

    In your call, pick ShareSwitch from the window list. You do this once, at the start.

  2. 2

    Hold Ctrl+Alt

    A violet frame follows your cursor and shows the window you're about to send.

  3. 3

    Click. Switched.

    Your call sees the new window immediately. Nobody waits, and nobody asks if they can see it now.

Built to be trusted.

It's a screen-sharing tool with a global hotkey. You should be sceptical of that, so here's exactly what it does.

No network code at all

Questions

Windows says “Windows protected your PC”. Is that a problem?

That's SmartScreen reacting to a new, unsigned app, not a detection of anything harmful. Click More info, then Run anyway, or build it from source if you'd rather verify it yourself. The installer scans clean on VirusTotal: 0 of 69 security vendors flagged it.

Does it work with my video call app?

Anything that can share a single window: Teams, Zoom, Google Meet, Slack huddles, Discord, OBS. To them, ShareSwitch is just a normal window.

Do viewers see my mouse cursor?

Not yet. The Windows feature used for mirroring doesn't include it. Great for documents, designs and dashboards; less so for demonstrating precise clicks.

Does it slow my computer down?

No. The mirror is drawn by the Windows compositor itself: no video encoding, no capture loop. It idles at essentially zero CPU.

Is there a Mac version?

Not today. macOS has no equivalent of the Windows feature this is built on, so it would be a full rebuild. If you'd use it, tell us on GitHub.
