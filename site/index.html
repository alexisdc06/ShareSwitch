One window, any content

ShareSwitch opens a proxy window that mirrors any other window, live. You share that one window once — everything after happens inside it.

1

Share the ShareSwitch window

In your call, pick "ShareSwitch" from the window list. Do this once, at the start.

2

Hold Ctrl + Alt

A highlight frame follows your cursor, showing which window you're about to send.

3

Click. Done.

Your viewers see the new window immediately. The call never noticed a transition.

Built to be trusted

It's a screen-sharing tool with a global hotkey. You should be sceptical of that — so here's exactly what it does.

No network code at all

No telemetry, no analytics, no update checks. Search the source for HttpClient — there are no matches.

The keyboard hook is minimal

Every key that isn't a modifier, Escape, a digit or an arrow is discarded inside the hook itself, before any other code sees it. Digits and arrows only pass while a modifier is held.

Open source, MIT

Every line is readable on GitHub, and you can build it yourself with one command.

No admin rights

Installs per-user. Or run the portable .exe with no install at all.

Questions

Windows says "Windows protected your PC" — is that a problem?

That's SmartScreen reacting to an unsigned app, not a detection of anything harmful. Code-signing certificates cost a few hundred euros a year, which is hard to justify for a free tool. Click More info → Run anyway, or build from source if you'd rather verify it yourself.

Is there a Mac version?

Not currently. macOS has no equivalent of the Windows compositor feature this is built on, so it would be a full rewrite rather than a port. If you'd use it, add your voice to the issue tracker.

Do my viewers see the mouse cursor?

No — the Windows API used for mirroring doesn't include the cursor. Fine for showing documents, designs and dashboards; less ideal for demonstrating precise clicks.

Does it slow my machine down?

No. The mirroring is done by the Windows compositor itself, which is already drawing those windows. There's no video encoding, no capture loop, and it idles at essentially zero CPU.

Will it work with my conferencing app?

It works with anything that can share a single window — Teams, Zoom, Google Meet, Slack huddles, Discord, OBS. ShareSwitch is just a normal window as far as they're concerned.
